# MentionEffects

Automatically applies animated Discord role-color effects to:

- Messages
- Mentions
- Reply previews

## Installation

Step 1 — download it from your GitHub

From your Vencord folder, run in PowerShwell:

cd "C:\Users\moham\Documents\Vencord\src"

Then:

git clone https://github.com/Zayton76/MentionEffects.git userplugins\mentionEffects

Step 2 — build it

Go back to the Vencord folder:

cd "C:\Users\moham\Documents\Vencord"

Then run:

pnpm build

Step 3 — inject the rebuilt Vencord

Run:

pnpm inject

Wait for it to finish, then fully restart Discord.

After Discord starts, check:

Vencord → Plugins → MentionEffects
